Voxora

Self-hosted PHP platform for secure AI text-to-speech, voice management and workflow automation

Get started →View on GitHub
$composer create-project voxora/voxora

Why Voxora?

Developers integrating high-quality voices face fragmented provider APIs, exposed keys and repetitive manual tasks. Voxora is a unified self-hosted PHP control plane that adds strong security, token scoping, batch automation and a clean dashboard, bridging raw TTS services and production apps.

Features

Everything you need, nothing you don't.

🔑

Secure Vault

Encrypted storage and scoped, auto-expiring API tokens with audit logs.

🌐

Unified Engine

Single interface for ElevenLabs, OpenAI TTS, Azure and local fallbacks.

⚡

Instant Synth

Generate, preview and download speech directly from the responsive UI.

📦

Batch Runner

Process CSV/JSON scripts into multiple MP3 files with one command.

📚

Voice Library

Curate, tag and reuse preset voices and generation parameters.

📈

Analytics Hub

Live history, cost tracking and usage charts in the dashboard.

🔌

REST + SDK

Full JSON API plus a clean PHP client for embedding in any app.

🔄

Webhooks

Notify external services when audio files are ready.

Get started

Three steps. Full docs live in the README.

Install
composer create-project voxora/voxora
Run
php -S 0.0.0.0:8080 -t public
Test
vendor/bin/phpunit
