## [0.1.0] - 2026-11-10

### Added

- Secure Vault — Encrypted storage and scoped, auto-expiring API tokens with audit logs.
- Unified Engine — Single interface for ElevenLabs, OpenAI TTS, Azure and local fallbacks.
- Instant Synth — Generate, preview and download speech directly from the responsive UI.
- Batch Runner — Process CSV/JSON scripts into multiple MP3 files with one command.
- Voice Library — Curate, tag and reuse preset voices and generation parameters.
- Analytics Hub — Live history, cost tracking and usage charts in the dashboard.
- REST + SDK — Full JSON API plus a clean PHP client for embedding in any app.
- Webhooks — Notify external services when audio files are ready.
