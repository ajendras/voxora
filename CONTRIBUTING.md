# Contributing to Voxora

Thanks for taking the time to contribute! 🎉 Every issue, idea and pull request helps.

## Getting started

1. Fork the repo and clone your fork:
   ```bash
   git clone https://github.com/<you>/voxora.git && cd voxora
   ```
2. Install dependencies:
   ```bash
   composer create-project voxora/voxora
   ```
3. Run the tests:
   ```bash
   vendor/bin/phpunit
   ```

## Making a change

- Create a branch: `git checkout -b feat/short-description`
- Keep pull requests focused — one feature or fix each.
- Add or update tests for behaviour you change, and update the README if the public API changes.
- Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `test:` …).
- Open the PR and fill in the template.

## Reporting bugs and ideas

Use the [issue templates](https://github.com/ajendras/voxora/issues/new/choose). For bugs, include steps to reproduce, what you expected and your environment.

## Good first issues

Look for the [`good first issue`](https://github.com/ajendras/voxora/labels/good%20first%20issue) label, or pick an unchecked item from the README roadmap.

By participating you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
